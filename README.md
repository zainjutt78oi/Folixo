## Run in VS Code (No BAT file needed!)

### First Time Setup
1. Extract `folixo_final.zip` to `D:\websites\folixo\`
2. Open VS Code → `File → Open Folder → D:\websites\folixo`
3. Open terminal in VS Code: `Ctrl + ~`
4. Run:
```
python run.py
```
That's it! Packages install automatically on first run.

### Every time after that
Just open VS Code terminal and:
```
python run.pys
```
OR press **F5** (after selecting Python interpreter once)

### Select Python Interpreter (one time)
`Ctrl+Shift+P` → `Python: Select Interpreter` → `./venv/Scripts/python.exe`
